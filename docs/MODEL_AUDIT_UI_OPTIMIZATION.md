# 模型审计 UI 优化说明

  - Mod 行最小高度从 96px 增加到 100px
  - 内边距从 12px/14px 统一增加到 16px

- **悬停效果**：背景透明度从 0.035 增加到 0.04

#### 策略列表优化
- **网格布局调整**：
  - Checkbox 列从 44px 增加到 56px
  - 控件列最小宽度从 150px 增加到 180px
  - 添加独立的 `.audit-strategy-checkbox` 容器
  - 策略内容区添加独立容器 `.audit-strategy-content`

- **间距改进**：
  - 行最小高度从 76px 增加到 84px
  - 垂直内边距从 10px 增加到 14px
  - 网格间距从 12px 增加到 16px
  - 控件间距从 8px 增加到 10px

- **对齐方式**：从 `align-items: center` 改为 `align-items: start`，避免内容被拉伸

#### 目标渠道编辑器
- **行高度**：从 72px 增加到 80px
- **内边距**：从 10px 增加到 14px
- **间距**：从 8px 增加到 10px

#### AI 分析模型区域
- **布局重构**：
  - 移除左侧 56px 的 padding
  - 改为顶部 20px + 底部 8px 内边距
  - 添加顶部和底部边框
  - 添加 4px 顶部外边距
  - 统一背景和边框样式

- **内容结构**：
  - 标题区域底部外边距 6px
  - 标题字重增加到 600
  - 说明文字独立显示块，顶部外边距 4px，行高 1.5

### 2. 档位预设系统（参考 gpt56_api_detector）

#### 后端实现
创建 `backend-go/internal/modelaudit/identity_presets.go`：

- **低档（Low）**：
  - 约 14 个请求
  - 8,000 tokens 预估
  - 启用：元数据一致性(1)、Reasoning 轮廓(6)、改写检查(2)、覆盖检查(4)
  - 不生成正式身份结论
  - 类似 gpt56 低档：基础 Juice + 元数据

- **中档（Medium）**：
  - 约 64 个请求
  - 35,000 tokens 预估
  - 全部策略启用，样本数适中
  - 生成正式身份结论
  - 类似 gpt56 中档：完整 Juice + 行为指纹

- **高档（High）**：
  - 约 200 个请求
  - 120,000 tokens 预估
  - 全部策略启用，样本数最大
  - 生成正式身份结论
  - 类似 gpt56 高档：全探针 + 多格式组合

#### 前端档位选择器
- **四档切换按钮**：
  - 低档 / 中档 / 高档 / 自定义
  - 每个按钮显示标题和预估请求数
  - 网格布局，4 列均分

- **档位描述**：
  - 选择非自定义档位时显示说明文字
  - 自定义档位显示提示信息

- **自动切换逻辑**：
  - 手动修改任何策略启用状态 → 自动切换到"自定义"
  - 手动修改样本数 → 自动切换到"自定义"
  - 选择预设档位 → 自动应用对应配置

### 4. 交互优化

#### 表单状态管理
- 添加 `identityPresetLevel` 字段到表单状态
- 新建任务默认选择"低档"
- 编辑任务时根据当前策略配置推断档位

- `applyIdentityPreset()` 函数根据档位应用配置
- `applyIdentityPresetToState()` 辅助函数用于初始化
- 保留用户对分析器的自定义设置

## 设计理念

### 参考 gpt56_api_detector
1. **清晰的档位划分**：低/中/高三档 + 自定义
2. **明确的请求数预估**：用户能提前了解成本
3. **自动检测自定义**：手动修改立即切换到自定义档
4. **正式结论标识**：明确标注哪些档位生成正式结论

### 视觉改进
1. **增加空间感**：更大的间距和内边距
2. **强化层次感**：更明显的字重和字号对比
3. **改进对齐**：策略列表顶部对齐，避免拉伸变形
4. **独立区域**：AI 分析区域视觉独立，边框包围

### 可用性提升
1. **更清晰的标签**：更大的字体和字重
2. **更舒适的点击区域**：增加按钮和行高度
3. **更好的视觉反馈**：优化悬停效果
4. **移动端友好**：响应式档位选择器
