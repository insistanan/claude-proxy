# 调度、持久化、渠道展示与报告

## 1. 持久化边界

使用独立 SQLite 表保存审计域数据，不把大量样本塞入 `config.json`，也不复用生产健康指标表表达能力结果。配置文件只保留必要的全局功能开关或数据库位置。

建议实体：

- `audit_jobs`：任务定义、启用状态、策略/任务包配置和调度规则。
- `audit_job_targets`：一个任务中的多个渠道目标及模型、协议、档位选择。
- `audit_runs`：一次任务运行及配置快照、状态、预算和时间。
- `audit_samples`：单次请求样本、特征、usage、耗时和脱敏证据引用。
- `audit_strategy_results`：策略原始结果、版本、基线和错误。
- `audit_reports`：身份、混用、能力及汇总报告快照。
- `audit_artifacts`：可选 HTML 报告元数据，不在数据库复制秘密。

所有外键使用稳定渠道 ID 和渠道类型。删除渠道后保留历史报告，并标记目标已不存在；不得把历史关联到占用相同数组下标的新渠道。

## 2. 任务配置

任务创建时必须选择至少一个渠道。每个目标允许：

- 指定协议；默认采用渠道所属 ChannelKind。
- 指定模型；留空则在每次运行开始时解析渠道默认模型，并保存解析结果。
- 指定思考档位；不指定则使用协议/渠道默认值并记录为 `default`。
- 选择策略集或能力任务预设。

调度支持：开始时间、可选结束时间或持续时间、执行间隔、时区、随机抖动、单轮样本上限、请求/token 预算和并发上限。允许无限期运行直到用户关闭。

默认间隔 24 小时；首期服务端建议校验 6 小时至 30 天。上下限作为集中配置常量和 API 能力返回，不散落在 UI。若未来用户明确调整合理范围，只修改一处合同。

## 3. 调度状态机

```text
draft -> enabled -> running -> enabled
enabled -> paused -> enabled
enabled/paused -> expired
running -> partial/failed -> enabled 或 expired
任意非 running -> deleted（软删除任务，保留历史）
```

- 同一 Job 不允许并发运行；多实例场景使用数据库租约或等价锁。
- 计划时间加入稳定随机抖动，避免大量渠道同时收到规律探针。
- 服务停机期间错过的周期直接跳过，只计算下一次未来执行时间。
- 用户手动运行不改变定时计划；若定时实例正在运行，应拒绝或进入明确队列，不重入。
- 任务到达结束时间时不再创建新 Run；进行中的 Run 按已冻结预算完成或取消。
- 取消必须使未执行样本停止，并将已有样本保存为部分结果。

## 4. 渠道列表摘要

每个渠道默认展示最新有效摘要：

- 能力总分和置信区间或覆盖率提示。
- 身份状态：符合、疑似替换、疑似混用、证据不足、未检测。
- 混用风险或估计比例摘要。
- 总体置信度、样本数和检测时间。
- 过期、任务进行中、部分失败或协议不支持状态。

摘要不覆盖现有健康/延迟字段。身份风险与生产健康状态使用不同颜色、标签和 API 字段，避免用户误解。

摘要的新鲜度阈值随报告类型或策略集配置；超过阈值显示“已过期”，不继续显示成当前事实。

## 5. 详情页

详情页围绕高频查看流程组织：

1. 顶部摘要：渠道、协议、模型、档位、报告时间和结论。
2. 独立标签页或分区：身份与混用、能力、稳定性与性能、运行样本、配置与版本。
3. 可视化：各能力维度雷达或条形图、置信区间、混用比例、时间趋势和样本状态分布。
4. 证据：策略版本、基线哈希、任务包版本、脱敏请求轮廓、SSE/错误摘要。
5. 操作：手动检测、创建/编辑低频任务、取消当前运行、导出 HTML。

界面不使用拖拽编排。策略使用开关、分组、数值输入和预设；危险或高费用组合在提交前显示请求量与预算。

## 6. HTML 报告

报告为单个自包含 HTML 文件，内嵌必要 CSS 和图表数据，不依赖外部 CDN。默认包含摘要、维度图表、混用估计、策略证据、运行参数、版本、限制声明和生成时间。

默认脱敏：不包含 API Key、Authorization、完整渠道秘密、保留题答案或未经选择的完整用户输入。导出内容来自冻结报告 DTO，不能在浏览器重新计算分数。

## 7. 管理 API

API 至少覆盖：策略和能力清单、任务 CRUD/启停、手动运行、运行取消、运行列表和详情、渠道最新摘要、报告详情和 HTML 导出。所有写操作使用稳定 ID、版本/ETag 或等价并发控制，状态冲突返回 409 类显式错误。

分页、保留期和清理必须避免一次加载全部样本。清理历史报告时保留任务和渠道配置，不触碰生产请求日志。

## 8. 验收条件

- 多渠道任务在重启后可恢复，错过周期不补跑，同一任务不重入。
- 可配置开始/结束或持续时间、6 小时至 30 天间隔、预算和抖动。
- 模型留空时每次运行保存实际解析模型；无法解析时明确失败。
- 渠道列表默认显示最新摘要、置信度和时间，未检测/过期/样本不足清晰可见。
- 详情页可追溯到样本、策略、基线、任务包和执行轮廓。
- HTML 报告自包含、可视化、默认脱敏且不重新判分。
- 检测结果不会改变生产渠道状态、权重或调度。
