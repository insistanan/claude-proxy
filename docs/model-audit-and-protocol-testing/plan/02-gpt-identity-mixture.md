# GPT 身份与混用检测

## 1. 能力边界

首期对 GPT-5.6 Sol 提供最完整的专项检测，并允许导入 Terra/Luna 对照基线。其他 GPT 型号只运行适用的通用策略；缺少可信基线或样本时必须输出“证据不足”，不能把声明模型名或单一行为当作高置信身份证明。

检测是黑盒统计审计，不是密码学证明。完全掌握探针、能按请求自适应路由的恶意中转可以规避固定探针，因此报告必须陈述威胁模型和结论强度。

## 2. 策略插件合同

每个策略声明：

- 稳定 ID、语义版本、实现版本和配置 Schema。
- 适用模型族、具体模型、协议、请求轮廓、上下文区间和思考档位。
- 请求生成器、随机种子规则、最大样本数和费用估算。
- 响应归一化器、特征提取器、判分器和失败分类。
- 所需基线 ID、基线版本、最低样本量和正式结论资格。
- 可与哪些策略组合、是否允许并行、是否含容易被识别的固定文本。

策略注册表负责启停、参数校验和版本冻结。新增策略不修改 Runner 主流程；不适用策略返回带原因的 `skipped`，配置错误直接拒绝运行。

## 3. GPT-5.6 专项信号

首期实现或 clean-room 重实现以下方法：

1. Juice 行为信号：提取推理强度相关输出并检查范围、稳定性及轮廓差异。
2. `32/48 -> 40...` 改写检查：作为可解释行为信号，不独立决定身份。
3. 合成 Juice 覆盖检查：识别上游通过提示词注入伪造固定数值的迹象。
4. 概率行为探针：国家、鸟、strawberry 等多组一 token 或短输出分布。
5. 模式差分：normal、Codex-compatible、Native Codex 以及短/长上下文下的行为变化。
6. 元数据一致性：返回 model、usage、reasoning tokens、响应结构、终态和协议能力是否互相矛盾。
7. 重复与变形探针：语义等价改写、顺序扰动或语言变化后，特征是否保持合理关系。

Juice 属于高解释性但非官方稳定合同。OpenAI 官方文档确认 reasoning 配置和 reasoning token usage 等字段，不把 Juice number 定义为公开身份字段。

## 4. 统计判定

- 分布距离：Jensen-Shannon divergence 及带平滑的似然比较。
- 温度和渠道噪声：通过校准参数避免把普通随机性误判为替换。
- OOD：样本不符合任何已知基线时输出未知/异常，而不是强行归到最接近模型。
- 混合估计：使用 EM 或等价混合模型估计候选来源比例，并报告区间而非单点。
- 时序检测：滚动窗口、变化点或序贯统计区分固定替换、随机混用、阶段切换和短期异常。
- 多信号融合：先保留每个策略结果，再由版本化聚合器计算身份结论和置信度。

聚合器不得把相关性很强的多个派生特征当作独立证据重复加权。单次运行样本不足时可以展示观察值，但不能生成正式“未混用”结论。

## 5. 基线治理

基线资产包含：稳定 ID、目标模型、适用协议/档位、采集窗口、样本规模、特征 Schema、来源、生成方法、许可证或授权说明、内容哈希和兼容策略版本。

参考仓库的 `trusted_likelihood_v2.json` 证明检测器自带冻结可信基线，不要求用户每次提供可信 API；但该仓库没有明确许可证，因此本项目首期只提供：

- 对受支持 Schema 的显式导入和校验。
- 导入后保存来源路径、哈希和“本地外部资产”标记。
- 缺少授权信息时不把资产复制进仓库、发布包或默认配置。
- 没有适用基线时，只运行无需基线的策略并降低结论等级。

未来若用户获得授权或自行采集可信数据，可把资产升级为可分发内置基线，但不得静默覆盖旧版本。

## 6. 结果模型

每次身份报告分别输出：

- 声明模型、请求模型、实际返回模型和协议轮廓。
- `matched`、`suspected_substitution`、`suspected_mixture`、`unknown`、`insufficient_evidence` 或 `unsupported`。
- 总置信度、样本数、适用策略数、跳过策略及原因。
- 各策略原始特征、距离/似然、阈值、基线 ID 和版本。
- 混用候选、比例估计、区间和时序窗口。
- 可能的替代解释：温度、协议转换、系统提示、上下文截断、限流或服务异常。

对外文案使用“符合/疑似/证据不足”，不使用“100% 真模型”或“已证明造假”。

## 7. 反探针与长期扩展

首期框架需允许后续增加：轮换题池、带密钥的随机实例生成、跨语言变形、工具调用特征、长上下文检索、token/logprob 指纹、延迟分布、隐藏挑战集和跨渠道对照。固定探针不能全部暴露在前端 API 响应中；报告只展示足以复核的脱敏证据。

## 8. 验收条件

- 策略可以独立启停、组合、调参和版本化，错误配置显式失败。
- GPT-5.6 Sol 专项信号至少覆盖 Juice、改写/覆盖检查、概率分布、模式差分和元数据一致性。
- 模拟数据可以区分单一匹配、固定替换、已知比例混合、未知 OOD 和样本不足。
- 报告能够追溯策略版本、基线哈希、样本和聚合器版本。
- 无许可证参考代码和基线没有进入项目发布资产。
- 威胁模型和结论局限在 UI 与 HTML 报告中可见。
