## 3. Outcome

管理员能够选择一个或多个具体渠道，通过手动或受控低频任务执行协议真实的模型请求，获得可追溯的 GPT 身份、模型替换/混用和通用能力结果；五种协议的快速测试与演武台共享可靠的后端执行、流解析和错误诊断，结果在渠道摘要、详情页和自包含 HTML 报告中清晰展示，且不会自动改变生产渠道状态。

## 4. Deliverables

- 独立 `internal/modelaudit` 子系统及清晰的执行器、协议、策略、评分、调度、存储和报告边界。
- Messages、Responses、Chat、Gemini、Images 的统一快速测试与演武台执行路径。
- GPT-5.6 Sol 专项身份检测、Terra/Luna 基线兼容和其他 GPT 通用信号框架。
- 固定替换、随机/比例混用、阶段切换和证据不足判定。
- 七维通用能力评分、汇总指数、覆盖率和置信区间。
- 手动与多渠道低频定时任务、持久化历史及预算/不重入保护。
- 渠道列表摘要、审计详情页和默认脱敏的自包含 HTML 报告。
- 不联网模拟验证与用户真实渠道验收清单。

## 5. 非目标

- 不自动暂停、删除、降权、切换渠道或修改负载均衡。
- 不做邮件、Webhook 或第三方通知。
- 不把能力指数称为 IQ，不宣称黑盒检测是密码学证明。
- 不直接复制无许可证参考代码和冻结基线。
- 不建设公开排行榜、云端题库服务或分布式调度。

## 7. 约束与边界

### 7.1 工作方式

- 始终遵守仓库 `AGENTS.md`，使用简体中文协作。
- 遵循 SOLID、KISS、DRY、YAGNI，修复根因，不以静默兜底掩盖协议错误。
- 任何时刻最多一个主线处于进行中；原子推进后覆盖更新 Status。
- 工作区可能存在用户改动，必须识别归属并避免覆盖。
- 执行层、审计判定和生产健康/调度保持职责隔离。

### 7.2 文件、资料和外部权限

- 允许修改当前仓库中实现本 Goal 必需的后端、前端、配置迁移和模拟测试文件。
- `D:\code\project\test\checkapi\gpt56_api_detector` 及网络资料只读参考，不修改，不直接复制无许可证内容。
- 不读取、打印、写入或提交真实 API Key；报告和测试夹具必须脱敏。
- 不调用真实渠道、第三方模型、计费 API 或外部通知系统。
- 不执行发布、部署或修改外部系统状态。

### 7.3 验证边界

- 允许静态检查和明确不联网的纯函数、mock server、`httptest` 或固定夹具模拟测试。
- 未经用户后续授权，不执行真实渠道验证、全项目测试、完整前端 type-check、构建、打包或发布。
- 模拟测试不得读取真实 `.config`、环境密钥或默认网络端点。
- 无法在授权内验证的行为必须进入用户验收清单，不得声称已验证。

1. 预定业务与代码产物真实落地，不只留下分析或 TODO。

3. 错误、unsupported、样本不足和协议边界均显式表达。
4. 已执行当前任务获授权的静态或模拟验证并保留证据。
5. Status 已覆盖更新且只指向一个下一动作。
6. 任务账本状态已同步，改动归属仍可区分。

## 15. 阻塞、取消与停止条件

仅在以下情况下停止并请求用户裁决：

- 完成当前主线必须调用真实渠道、运行未授权验证或改变外部系统。
- 必须复制、修改或发布无明确许可证的参考资产。
- 需要破坏性配置/数据库迁移且不存在无损路径。
- 稳定渠道 ID 或数据真相源与代码事实冲突，无法在当前边界修复。
- 官方协议和必须支持的私有协议存在需要产品取舍的不可兼容分歧。
- 用户改动与 Goal 必改区域冲突且无法安全合并。

普通困难、耗时、首次模拟失败或仍存在可验证路径时不得标记 blocked。只有用户可以取消 Goal、放弃主线或扩大授权。
